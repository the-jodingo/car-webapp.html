# Odingo — Car Showroom Landing Page

A single-page landing site for a fictional Italian performance-car marque
("Odingo — Italian Excellence Since 1947"), featuring the Odingo 296 GTB.

## Tech

Plain HTML, CSS, and vanilla JavaScript — no build step, no dependencies.

## Run

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Structure

- `index.html` — the entire site: hero, spec sections, gallery, contact
